# Rahul Keshri — AI Portfolio

> A futuristic, AI-powered developer portfolio built to showcase my software engineering journey, projects, technical skills, and GenAI work.

🌐 **Live Portfolio:** https://rahul-keshri-dev-ai.netlify.app/

---

## 🚀 About

This is my personal developer portfolio designed around an AI/ML-inspired interface.

Instead of being a traditional static portfolio, it combines a modern futuristic UI with interactive features that allow recruiters and visitors to explore my:

- Software engineering skills
- Full-stack development experience
- GenAI & AI projects
- Technical projects
- Education and experience
- Resume
- Contact and social profiles

The portfolio also includes an interactive AI assistant and a dedicated **Recruiter Mode** for quickly exploring my professional profile.

---

- 🤖 **AI Portfolio Assistant**
